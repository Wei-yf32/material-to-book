# 质检清单（qa-checklist）

分两层：脚本能查的（必须全绿），人眼才能查的（抽查不少于 6 页/卷）。

## 一、脚本门（失败即返工）

```bash
PY=python   # 需 3.12 + pymupdf

# 1) 全卷结构
$PY _build/tools/checkbook.py
#    · 缺图/缺 INCLUDE 目标 → 必须为 0
#    · 每章汉字数 < 1200 → 警告，< 8000 视为"搬运"，返工

# 2) 单章静态体检
$PY _build/tools/preview.py "_build/vol/vol4/03_xxx.html" --check
#    · 未转义代码、禁止标签、$ 公式、表格缺 thead、标题层级跳跃

# 3) 单章渲染 + 越界
$PY _build/tools/preview.py "_build/vol/vol4/03_xxx.html" --pdf
#    · 文本块越出页面（x1>w-20 或 y1>h-10）→ 修表格/图宽/长公式

# 4) 编号一致性
$PY _build/tools/numcheck.py vol4
#    · 图/表/实验/式编号前缀必须等于章号；跨章引用指向的小节必须存在

# 5) 公式裸 < 兜底
$PY _build/tools/fix_lt.py vol4 vol5
#    · 报 >0 处就 --apply，然后重跑 preview

# 6) 合订后
$PY _build/tools/verify_book.py "<书名>.pdf"
#    · 越界块 0、近空白页 0、一级书签为卷名、卷起始页连续
$PY _build/tools/scan_latex.py "<书名>.pdf"
#    · 残留未渲染 LaTeX（代码里的 \n、\( 属误报）
```

## 二、内容自检（每章逐项打勾）

- [ ] 章首有"导入"（真实事件 + 落到本章问题），不是"本章介绍"。
- [ ] 有 `box key` 目标，4~6 条，每条可验收。
- [ ] 至少一个 `例子：` 小节，含完整手算，每步有中间值。
- [ ] 公式里每个符号都解释过；`<` 已转义。
- [ ] 每个实验八节齐全（目的/要求/文件结构/阅读顺序/数据/代码/输出/动手改）。
- [ ] 每个 `def`/`class` 有中文 docstring（作用/参数/返回/关键实现/边界）。
- [ ] 代码块前有导语、后有分段讲解；顶部有文件条。
- [ ] 每张图能在正文里被引用；图注写了数据来源与脚本。
- [ ] 每个数字能追到脚本或材料。
- [ ] 章末有覆盖表，第三列无"不采纳"，页码覆盖本章全部原始页。
- [ ] 正文无"课件第 N 页讲了……"的指路句（`grep -c "课件 p"` 为 0，影印图注除外）。
- [ ] 禁用词清单清零（首先/其次/综上/值得注意/众所周知/不难发现/让我们）。

## 三、人眼抽查（脚本查不出"丑"）

每卷至少 6 页，优先挑这些位置：

1. **卷首页/目录页**：页码是否指向真实起始页（不是目录自己那页）。
2. **代码块首尾**：文件条是否贴在上面、跨页时是否断了半行、深色输出块有没有被切。
3. **宽表**：是否有列被压成两行、是否有表格超出右边距。
4. **公式页**：行内公式是否比正文大一号、独立公式上下留白是否一致、有没有出现源码。
5. **图页**：SVG 是否模糊、中文标签是否变方框、图注是否和图分离到两页。
6. **覆盖表页**：表格是否跨页时重复表头、页码列是否连续。
7. **影印页**（若启用）：影印图是否清晰、图注是否写明"第 N 页 / 共 M 页"。

## 四、交付前一致性

- [ ] 合订 PDF 页数 = 各卷页数之和（含封面与目录）。
- [ ] 书签数与标题数一致；一级书签 = 卷名。
- [ ] `交付说明.md` 的数字与 PDF 实际一致（页数、字数、图表数、实验数）。
- [ ] `分卷PDF/` 与 `_build/pdf/` 内容一致（重新复制，不要留旧版）。
- [ ] 备份上一版（`_build/backup/`），便于对比与回滚。
